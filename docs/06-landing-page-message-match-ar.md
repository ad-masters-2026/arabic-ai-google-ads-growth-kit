# Landing Page Message Match

## الفكرة

Google Ads لا يعمل وحده. الإعلان والكلمة وصفحة الهبوط يجب أن يتكلموا نفس اللغة.

## Above the Fold Checklist

- Headline واضح يتطابق مع نية البحث
- Subheadline يشرح النتيجة
- CTA واضح
- Proof أو Trust signal
- صورة/تصميم يدعم الخدمة
- سرعة تحميل جيدة
- تجربة جوال ممتازة

## مثال

Keyword theme:
"إدارة حملات جوجل ادز"

Landing headline:
"إدارة حملات Google Ads لزيادة الليدز وتقليل الهدر الإعلاني"

Subheadline:
"نساعدك في بناء Structure صحيح، تتبع التحويلات، تحسين الكلمات، وتوسيع الحملات بمساعدة AI وتحليل الأداء."

CTA:
"احجز استشارة مجانية"

## AI Landing Page Audit Prompt

راجع صفحة الهبوط التالية لحملة Google Ads. قيّم:
1. هل الرسالة متطابقة مع نية البحث؟
2. هل العرض واضح خلال 5 ثواني؟
3. ما الاعتراضات غير المجاب عنها؟
4. ما عناصر الثقة الناقصة؟
5. ما CTA الأفضل؟
6. ما الكلمات التي يجب إضافتها للصفحة لتحسين التطابق؟
7. اقترح نسخة Hero Section أقوى.
