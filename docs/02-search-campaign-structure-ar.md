# هيكل حملات Search لجوجل أدز

## الهدف

بناء هيكل واضح يسهل التحكم في النية، الميزانية، الكلمات السلبية، جودة الليدز، والرسائل الإعلانية.

## الهيكل المقترح

### 1. Brand Campaign

تستهدف اسم البراند فقط.

أمثلة:

- اسم الشركة
- اسم الخدمة + اسم الشركة
- أخطاء كتابة اسم البراند

الهدف: حماية الطلب الموجود وقياس الطلب المباشر.

### 2. Core Service Campaign

تستهدف الكلمات التجارية الأعلى نية.

أمثلة لو الخدمة تسويق:

- شركة إدارة حملات جوجل
- إدارة حملات جوجل ادز
- وكالة إعلانات جوجل
- شركة تسويق إعلانات جوجل

### 3. Category Campaigns

تقسيم حسب الخدمة أو القطاع:

- Google Ads for E-commerce
- Google Ads for Lead Generation
- Performance Max Management
- YouTube Ads
- Shopping Ads
- Conversion Tracking / GA4

### 4. Problem-Aware Campaign

لمن يبحث عن المشكلة، وليس اسم الخدمة.

أمثلة:

- مبيعات المتجر قليلة
- تكلفة الإعلان عالية
- كيف أزيد الطلبات من جوجل
- ليه حملات جوجل لا تحقق نتائج

هذه تحتاج صفحة محتوى قوية أو عرض استشارة.

### 5. Competitor / Alternative Campaign

لا تبدأ بها إلا بعد ضبط الأساسيات. تحتاج رسائل قانونية ومحترمة وتجنب استخدام علامات تجارية بشكل مخالف للسياسات.

## Match Type Strategy

| المرحلة | Match Types |
|---|---|
| البداية | Exact + Phrase |
| بعد جمع بيانات | Phrase + Broad محدود |
| مع Smart Bidding قوي | Broad مع إشارات تحويل عالية الجودة |
| كلمات عالية التكلفة | Exact فقط غالبًا |

## Negative Keywords

ابدأ بقائمة عامة:

- مجاني
- وظيفة
- وظائف
- دورة
- كورس
- شرح
- PDF
- تحميل
- نموذج
- راتب
- تدريب
- تعلم
- تسجيل دخول
- خدمة العملاء

ثم أضف كلمات خاصة بكل قطاع.

## Ad Group Logic

كل Ad Group يجب أن يكون له:

- Theme واضح
- 3-10 Keywords متقاربة
- إعلانات مرتبطة بالنية
- Landing page مناسبة
- Negative keywords تمنع التداخل

## Ad Copy Framework

صيغة الإعلان:

1. الخدمة الأساسية
2. النتيجة أو الوعد
3. إثبات أو آلية
4. CTA واضح

مثال:

- إدارة حملات Google Ads باحتراف
- تحسين الليدز وتقليل الهدر الإعلاني
- Strategy + Tracking + Scaling
- احجز استشارة الآن

## Quality Control Checklist

- هل الكلمات في الإعلان موجودة في صفحة الهبوط؟
- هل CTA واضح فوق الفولد؟
- هل الخدمة مفهومة خلال 5 ثواني؟
- هل توجد أدلة ثقة؟
- هل يوجد رقم/واتساب/فورم؟
- هل التحويلات تعمل؟
- هل الكلمات السلبية مضافة؟
