# أدوات عربية لجوجل أدز بالذكاء الاصطناعي

مشروع مفتوح المصدر لمساعدة المسوقين العرب على بناء، تحسين، وتوسيع حملات Google Ads باستخدام قوالب عملية وعمليات مدعومة بالذكاء الاصطناعي.

> المشروع غير تابع لجوجل. الهدف تعليمي ومجتمعي.

## فكرة المشروع

في السوق العربي، أغلب الموارد القوية لجوجل أدز تكون بالإنجليزية، وغالبًا لا تراعي:

- سلوك البحث العربي
- اختلاف اللهجات والكلمات المحلية
- حملات الليدز في السعودية والخليج ومصر
- الكلمات السلبية العربية
- صفحات الهبوط العربية والإنجليزية
- تقارير الوكالات
- استخدام الذكاء الاصطناعي بشكل عملي في الأداء الإعلاني

هذا المشروع يحاول تجميع نظام عملي للمسوقين العرب.

## محتويات المشروع

- Playbooks لجوجل Search و Performance Max
- مكتبة Prompts للذكاء الاصطناعي
- قوالب CSV للحملات والكلمات السلبية
- قالب تقييم جودة الليدز
- أدوات Python بسيطة لتنظيف الكلمات وتجهيز الهياكل
- قوالب تقارير أسبوعية
- Checklist لقياس التحويلات والرسائل الإعلانية

## بداية سريعة

1. افتح ملف `docs/01-ai-google-ads-operating-system.md`.
2. املأ قالب `templates/ai_keyword_research_brief.md`.
3. استخدم مكتبة البرومبتات في `prompts/google_ads_ai_prompt_library.md`.
4. نظف الكلمات السلبية باستخدام `tools/negative_keyword_cleaner.py`.
5. جهز هيكل الحملة من `templates/search_campaign_structure_template.csv`.

## فلسفة المشروع

الذكاء الاصطناعي لا يغني عن خبرة المسوق، لكنه يساعد في:

- تسريع البحث والتحليل
- اكتشاف نوايا البحث
- بناء قوائم كلمات سلبية
- تحسين الرسائل الإعلانية
- مراجعة صفحات الهبوط
- اتخاذ قرارات Scaling بشكل أكثر أمانًا
